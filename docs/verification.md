## 检查命令

```sh
go test ./...
go test -race ./...
go vet ./...
node tests/browser.cjs
node scripts/test-guardian.cjs dist/server-windows-x64/codex-remote.exe
```

浏览器测试需安装对应浏览器及测试依赖；race 检查需支持的 Go/C 工具链。客户端检查见[客户端文档](../client/README.md#验证)。测试使用隔离数据，真实桌面联调单独进行。
