# 手机排版与内容显示

本页描述 Codex Remote 的消息阅读器，不代表与 Codex 桌面的全部界面一致。

| 内容 | 当前行为 |
| --- | --- |
| Markdown | 标题、粗体、列表、引用、链接、表格、行内代码及代码块。长代码和表格独立横向滚动，代码可复制。原始 HTML 按文字显示。 |
| 数学公式 | KaTeX 渲染 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`；可见时加载，超长或不支持的表达式保留可读源码。 |
| 图片 | Markdown 图片及日志中带可读取地址的图片附件，点击加载、点击放大。支持常见 PNG、JPEG、GIF、WebP；本地文件还需通过 MIME 检查。 |
| GIF | 点击播放，可停止；切到后台时停止并释放图片节点。 |
| Mermaid | `mermaid` 代码块点击“显示图表”，可切回源码、放大或适应屏幕。语法错误保留源码；限制 16,000 字符、150 条边。 |
| 视频／音频 | Markdown 媒体链接或图片式引用转为原生控件，点击加载，无自动播放、无预加载，后台暂停。实际解码取决于设备和编码。 |
| 桌面专用内容 | 审批、工具专用卡片、交互应用、文件 diff 面板不在本次显示适配范围。日志仅有占位、数据内嵌图片、已删除文件、需额外登录的远程媒体无法保证显示。 |

本地媒体地址示例：`![预览](</absolute/path/a photo.png>)`、`[视频](/absolute/path/demo.mp4)`。相对地址按该聊天的项目目录解析。`/api/media` 需要当前登录会话，并校验对应 thread/message 中确实引用了请求地址；不提供任意文件下载。仅允许常见图片、音视频 MIME，浏览器访问的服务端文件上限 256 MiB，App 原生层单个媒体上限 32 MiB；不读取目录和最终路径为符号链接的文件。支持 Range，便于视频拖动。SVG、HTML、普通文档不通过此接口提供。

远程 HTTP(S) 媒体由手机在点击后直接访问原地址，本机服务器不代理外网请求。渲染库从电脑随程序提供，不向 CDN 请求；现有聊天同步仍走本机/Tailscale。协议相对 URL、javascript URL 和原始 HTML 不转成可执行内容。

## 手机布局与资源

保留 iPhone 安全区、visualViewport 键盘适配、16px 输入字号、44px 触摸按钮。消息正文使用更清晰的标题层级与间距；宽内容在块内滚动，媒体限制在屏幕内，创建窗口限制高度并允许滚动。

Marked / DOMPurify 是基础解析器；KaTeX 按可见公式加载，Mermaid 只在用户点击时加载，每种库每页一次。大媒体默认不下载，视频 `preload=none`。没有新增轮询或常驻 Node 进程，Go 可执行文件包含前端资源。约 4 MiB 的库资产主要是 Mermaid，仅点击图表时才传输。

版本和归档校验值记录在 `internal/server/web/vendor/manifest.json`，更新脚本为 `scripts/vendor-renderers.py`；许可证随资源保存。正常 Go 编译不需安装 npm 或联网。

## 刷新与打开会话

“设置”浮窗中的“打开会话”可选“跳到最新消息”（默认）或“恢复阅读位置”。刷新会恢复当前会话、搜索条件和归档筛选；同步模式和项目折叠状态继续保留。回到列表再刷新会停留在列表。

阅读位置按消息 ID 和消息内偏移保存，最多保留 50 个会话的位置。恢复时最多加载 200 条历史；原消息已超出范围时跳到最新并提示。默认跳到最新会跟随公式等异步排版变化；手动上滑阅读后不再强制跟随。

浏览器草稿保存在当前标签页的 sessionStorage；App 使用按连接隔离的本地存储。最多 20 个会话、每条 16 Ki 字符，发送成功删除草稿。会话位置、筛选和设置存于 localStorage，不存完整聊天内容。主动断开会清除保存的会话位置和草稿，保留显示偏好。隐私模式或浏览器清理存储可能使这些状态丢失。

渲染依赖只在 `internal/server/web/vendor` 维护一份。`client/ui/vendor` 是忽略 Git 的生成目录：网页服务和预览启动时通过 `scripts/sync-client-vendor.cjs` 同步，原生客户端通过 Cargo `build.rs` 同步，也可手动运行 `node scripts/sync-client-vendor.cjs`。客户端发行包仍包含完整离线资源，不依赖服务端提供字体。KaTeX 仅保留 WOFF2 及对应 CSS 引用；20 个字体覆盖不同数学字形和尺寸，不能按文件名相似直接删除。
