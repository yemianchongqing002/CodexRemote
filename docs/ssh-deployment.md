# 内网免口令与 SSH 快速安装

新版本服务默认免口令。客户端读取 `/api/status` 并确认软件版本兼容后进入聊天，丢失旧口令文件不会阻止连接。普通手动启动仍默认只监听 `127.0.0.1:8787`；内网远程连接需要指定监听地址和 `--allow-host`。可访问服务端口的设备可以读取和操作会话，Host、Origin 和只读限制仍生效。

如需原有认证，加 `--require-token`。只有此模式才读取或生成口令文件。该设置保存到守护配置的 `service.requireToken`，A/B 重启后保持。关闭口令不会删除原有口令文件、会话或队列。更新旧版本可执行文件后，未配置该字段的守护配置采用免口令默认值。

## 连接前的版本检查

当前软件版本为 0.2.0。`/api/status` 的 `version` 仍是聊天数据同步标记；新增 `release` 提供 `serverVersion`、`clientMin` 和 `clientMaxExclusive`。`GET /api/version` 在口令登录前也可读取同样的软件元数据，仍受 Host/Origin 限制，不包含机器名称、聊天或登录数据。兼容范围的下限包含、上限不包含；当前服务支持 `0.2.0 ≤ 客户端 < 0.3.0`，客户端也要求 `0.2.0 ≤ 服务端 < 0.3.0`。

新增电脑、选择已保存的电脑、页面重新打开及安装后连接，均先验证兼容范围。服务过旧（包括没有版本接口的旧服务）时显示“通过 SSH 更新目标服务”，经过 SSH 检测、账号登录和主机指纹确认，重装当前客户端携带的服务程序并保留所选端口，完成后再次检查版本。尚未确认版本兼容时，不进入聊天同步。

当前客户端过旧时显示本机客户端更新指引：网页需更新运行网页服务的电脑上的客户端并重启，桌面 App 需安装新版，然后重新检测。SSH 重装目标服务不会更新当前客户端。版本请求失败或返回无效范围时提示重新检测，不将通信故障直接判断为旧版并安装。发布不兼容的协议变更时应更新软件版本及双方兼容范围，并重新生成四个平台的服务包。

## 快速安装

在桌面客户端或网页客户端“我的电脑”页面：

1. 选择或填写电脑地址，先检查已有服务；服务可用时先检查软件版本和客户端兼容范围，兼容才连接。服务未启动时检查 SSH，收到有效 SSH 标识后才显示账号登录表单。
2. 点击“连接并安装”。首次连接在客户端核对并确认主机指纹；已知主机身份变化会阻止登录。
3. 自动识别系统，通过 SFTP 上传对应服务程序、校验 SHA-256、安装登录自启动并检查服务。
4. 自动保存连接并进入聊天。服务已启动但客户端无法访问时，保留连接并提示网络问题。

SSH 登录页面可点击“返回修改地址”，保留已填电脑地址并清空密码。服务安装完成后隐藏安装表单；网络暂时不通时，点击“服务已安装，重试连接”只检查并连接已安装的服务，无需重新输入 SSH 凭据或重复安装。检测过程中暂时禁用返回、端口修改和重复提交，防止异步结果切换到错误步骤。

网页和桌面客户端均先检测连接，再请求 SSH 凭据。SSH 无法连接时停留在连接检查页，区分端口拒绝、非 SSH 服务、超时或不可达；可修改 SSH 端口后重新检测，也可返回修改电脑地址。服务端口无法访问并不代表整台电脑离线。服务和 SSH 都无法访问时，先检查开机状态、地址、网络和防火墙，不进入登录或安装。

网页安装由运行 `client/web/server.cjs` 的电脑发起 SSH 连接，目标是安装引导中填写的 IP/主机名。浏览器不下载安装包，也不要求用户把安装包手动拷到目标。首次运行网页服务前，在 `client` 目录执行 `npm ci`，通过 `scripts/bundle-servers.cjs` 准备四个平台的服务程序。

网页中点击“通过 SSH 安装到这台电脑”，填写目标用户名和认证方式，自动识别系统与架构、SFTP 上传、校验、执行固定安装脚本，随后保存所填地址并尝试连接。保留所选服务端口；SSH 端口单独配置，默认 22。SSH 不通时无法远程安装，不会偷偷改成本机安装。

网页模式使用托管服务进程的 SSH agent 或 `~/.ssh/id_ed25519`、`~/.ssh/id_rsa`，不解析 SSH 别名或跳板配置。密码不写入磁盘、日志或命令参数。主机指纹按浏览器会话核对，检测与安装复用同一条认证连接；安装计划十分钟后过期且只能使用一次，不能由另一浏览器会话取用。原生客户端的主机信任及 SSH 配置行为见下文。

端口在“高级设置”中；默认沿用系统 SSH 配置。原生连接读取系统 `ssh -G` 配置中的主机、用户、端口和 IdentityFile，使用 SSH agent 或未加密私钥。加密私钥需先加入 agent。快速安装只支持直连，不支持 ProxyJump/ProxyCommand；不自动创建聊天 SSH 隧道。需要系统 OpenSSH 客户端用于解析配置。

登录界面在选择 SSH 密钥时明确标注认证方式，并在“连接凭据与数据说明”中列出密钥位置。当前不自动生成或另存用户私钥：网页端使用运行网页服务的账号的 SSH agent 或 `~/.ssh/id_ed25519`、`~/.ssh/id_rsa`；原生端使用当前设备的 agent 或系统 SSH 配置 `IdentityFile` 指定的密钥。私钥不发送到目标机器，网页端也不将私钥发送给浏览器。此说明不承诺完全不记录信息：连接配置在本地保存，原生端保存主机信任记录，目标 SSH 和安装进程可能产生日志。

密码仅在本次请求内存中使用，原生侧释放时清零，不写入配置、命令参数或日志。确认身份后才发送密码。检测成功后复用已认证的 SSH 连接安装，安装计划十分钟过期，不保存密码。主机信任保存在客户端应用数据目录的 `ssh_known_hosts`，并读取用户 `~/.ssh/known_hosts`。

Tailscale SSH 使用 tailnet 身份和 SSH none 认证，不尝试密码或密钥降级；地址必须解析为 Tailscale 地址。双方需已登录 Tailscale、目标开启 Tailscale SSH 且访问规则允许。需要网页验证的 check 策略目前会提示先完成验证，客户端尚不提供内嵌验证流程。Tailscale SSH 服务端仅支持 Linux 与开源命令行版本 macOS；Windows 和图形版 macOS 应选择密码/密钥模式，通过 Tailscale 地址连接普通 OpenSSH。当前自动安装包只覆盖 Windows/macOS，Linux 目标不支持自动安装。参见 [Tailscale 官方说明](https://tailscale.com/docs/features/tailscale-ssh)。

目标需要开启 SSH、安装 Codex，并以运行 Codex 的账号登录桌面。自动部署支持 Windows/macOS 的 x64 和 ARM64；手机 App 可连接部署后的服务，目前不能发起 SSH 安装。

## Windows 首次开启 SSH

网页未发现目标服务时，先检查目标 SSH 协议标识。SSH 可用就进入登录并自动上传 EXE、安装启动；Windows 服务最终位于 `%LOCALAPPDATA%\CodexRemote\codex-remote.exe`。上传先写临时文件，校验后再移动到安装目录。

SSH 检测失败时，网页在“重新检测 SSH”下方提供“下载安装版本”入口，展开目标系统选择和安装步骤。选择 Windows x64 后可下载已有 MSI；将文件传到目标电脑，双击并确认管理员权限，完成后回网页重新检测 SSH，再登录安装服务。macOS 提示开启远程登录，其他系统提示手动配置 SSH。下载 MSI 不等于已经安装远程服务，也不能修复网络不可达；仍可修改端口或返回修改地址。

目标尚未开启 SSH 时，可在目标本机运行 `CodexRemote-EnableSSH-x64.msi` 并确认管理员 UAC。MSI 安装固定引导程序，开启 Windows OpenSSH Server、自动启动及 SSH 防火墙规则；之后回网页用目标账号安装服务。MSI 制作步骤见 `packaging/windows/README.md`。

服务 EXE 也支持独立参数 `codex-remote.exe --enable-ssh`：非管理员执行时请求 UAC，管理员执行时直接操作，完成后退出。该参数不可与服务启动参数组合。正常服务运行不会请求管理员权限或自动开启 SSH。包的卸载不会关闭系统共享的 SSH。

## 自动发现 Tailscale

打开“我的电脑”会检测本机 Tailscale（含 macOS 应用内 CLI、常见包管理器路径及 Windows 安装目录），区分未安装、未登录、等待批准、停止及运行状态。未安装时提供官方下载入口；返回客户端后或点击“重新检测”刷新设备。

运行时读取 `tailscale status --json`，仅向界面提供电脑名称、MagicDNS 名称、Tailscale 地址、操作系统、在线状态和 SSH 主机密钥是否存在，不转发账号资料、认证 URL 或完整状态。选择在线设备自动填写 Tailscale IP；只有提供 SSH 主机密钥的目标才预选 Tailscale SSH，实际认证仍受访问规则和网页验证要求约束。在线状态不等于 SSH 或服务端口可达。

已有服务可点击“连接已有服务”，按默认 8787 端口保存连接并进入正常连接流程；自定义端口可用手动地址。未安装服务可继续一键 SSH 安装。原生客户端通过 SSH 登录后也会检查目标的 Tailscale 安装和运行状态，缺少时引导在目标安装并登录，不阻断已有内网部署，也不替用户修改 VPN 设置。没有可用网络或 SSH 凭据时，无法直接检查一台未出现在 Tailscale 列表中的远程电脑。

## 安装位置与行为

| 系统 | 服务目录 | 登录启动 |
| --- | --- | --- |
| macOS | `~/Library/Application Support/CodexRemote` | `local.codex-remote.ssh` LaunchAgent |
| Windows | `%LOCALAPPDATA%\CodexRemote` | `CodexRemote-SSH` 当前用户计划任务 |

安装服务监听 `:8787`，默认免口令，使用独立目录保存守护配置和队列。只运行项目携带的服务包和固定安装脚本，不允许网页提供任意执行命令。端口被其他程序占用时停止安装，不杀掉其他服务。更新保留上一个程序为 `.previous`；安装失败会显示具体阶段，需重新检查 SSH 后才能再次提交。不会删除目标电脑聊天，不会修改系统防火墙或为安装提升权限。

Windows 当前用户需要有注册计划任务的权限；macOS 需要该用户有可用 GUI 登录会话。缺少 Codex 可执行文件、目录、安装权限或桌面登录时会明确失败，不把文件上传完成当作部署成功。

### Windows SSH 安装权限与防火墙

Windows 自动部署要求当前 SSH 会话具备管理员权限，并通过 Tailscale IPv4 连接。安装脚本在修改安装前验证权限和 `SSH_CONNECTION` 来源地址，无法确认时明确失败，不尝试交互式 UAC 提权。

`CodexRemote-SSH` 任务使用当前账号的交互式桌面会话和最高权限；该用户仍需登录 Windows 桌面。首次启动前创建或更新 `CodexRemote-SSH-Tailscale` 入站规则，仅允许当前 SSH 来源 IPv4 访问此服务程序的 TCP 服务端口。已有针对该程序的显式阻止规则需要用户核对处理。程序路径或安装来源变化时重新安装会更新规则。

本机状态检查通过后仍需从客户端所在电脑检查服务地址；管理员权限不保证网络可达，也不消除系统策略或已有阻止规则。
